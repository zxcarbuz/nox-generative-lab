# NOX Generative Lab

Браузерная лаборатория генеративной графики: **12 математических миров**, которые можно переключать в одном интерфейсе.

## Возможности

- 12 визуальных режимов с собственными настройками
- палитры, скорость, плотность, длина следов, seed, качество
- пауза, скрытие HUD и полноэкранный режим для фоновой анимации
- экспорт текущего кадра в PNG
- адаптивный интерфейс для мобильных устройств
- один автономный `index.html`, без внешних библиотек и сборки

## Локальный запуск

Откройте `index.html` в браузере. Для более полного 3D-рендеринга нужен WebGL2.

## Управление

| Клавиша | Действие |
| --- | --- |
| `←` / `→` | переключение режимов |
| `1`–`9` | выбор первых девяти режимов |
| `Space` | пауза / продолжить |
| `H` | скрыть / показать интерфейс |
| `F` | полноэкранный режим |
| `S` | экспорт PNG |
| `R` | случайный seed |

На телефоне двойной тап по холсту скрывает или показывает HUD.

## GitHub Pages

После создания репозитория поместите `index.html` в корень ветки `main`. В GitHub перейдите в **Settings → Pages**, выберите **Build and deployment → Deploy from a branch**, затем **main** и **/(root)**. Сохраните настройки. До этого действия сайт в Pages не публикуется.

Предполагаемый адрес после включения публикации: `https://zxcarbuz.github.io/nox-generative-lab/` (заработает только после успешного развёртывания).

## Технические замечания

Это художественные симуляции, а не научно точные физические модели. Некоторые режимы используют приближённые вычисления. Самые ресурсоёмкие эффекты зависят от производительности GPU и поддержки WebGL2.
